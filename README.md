## Cleanse the Castle

This game was developed by a 2 person team and submitted as our university final year project.

Cleanse the Castle is a 2D roguelike video game developed using the Unity game engine.
The aim of the project is to design and implement a replayable game experience through the
use of procedural generation and system driven gameplay.

The game is built around several core systems, including player movement and combat,
procedural dungeon level generation, rule based enemy AI, a progression system and an
AI-driven narration feature. These systems work together to create a dynamic experience
where each playthrough differs in layout and outcome.

The game is divided into two main areas: the starting area and the dungeon. The starting
area acts as a safe zone where the player can equip a weapon and interact with NPCs,
while the dungeon represents the main gameplay loop, where the player progresses through
procedurally generated levels, encounters enemies, builds their character and fights bosses.
